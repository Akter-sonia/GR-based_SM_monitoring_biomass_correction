# Data description 
1. MIS_SM_Biomass_2023.csv contains combined data of preocessed MIRA EGR measurements, reference soil moisture and 
biomass data for 2023 on daily resolution. K_SM_Biomass_2023.csv contains similiar data for K-40 measurements. 
2.SM_pred_MIRA_2023.xlsx contains the calibration and prediction results for 2023 MIRS EGR measurements. SM_pred_K_2023.xlsx contains similiar results for K-40 measurements.
The model parameter β can be modified in the spreadsheet, and the resulting effects on the calibration and predicted soil moisture can be evaluated by running the Solver.
3. SM_pred_MIRA_calibration_summary_2023.xlsx contains the summarized calibration and prediction results for each β scenario (0-0.025). 
SM_pred_K_calibration_summary_2023.xlsx contains similiar results for K-40 measurements.
